== Enterprise Analytics Compatibility



The 1.1 releases of the Analytics SDK are fully compatible with all currently supported releases of Enterprise Analytics.
The 1.1 {name_platform} SDK also supports the poll-based {async-server-api-feature-name} introduced in self-managed Enterprise Analytics Server 2.2.
